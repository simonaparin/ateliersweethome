# Material Ledger Decision

Дата: 2026-07-25

## Решение

Выбран вариант:

```text
C / Material Ledger
```

Вариант B больше не является базовым. Его темные элементы можно брать как акцент, но основная система теперь C.

После просмотра вариантов внутри C принято уточнение:

```text
C2 / Photo Ledger как база + одна темная секция C3 / Dark Insert Ledger.
```

## Почему C

- лучше держит SEO-структуру;
- проще масштабируется на `/roof` и `/summer-kitchen`;
- не требует большого портфолио;
- позволяет честно показывать наблюдения, а не выдуманные кейсы;
- дает понятную страницу для человека, который пришел из поиска с конкретной проблемой.

## Что сохранить из B

- немного темных секций;
- кирпично-красный акцент;
- материальность: камень, дерево, металл, крыша;
- уверенный тон.

## Что не переносить из B

- полностью темную систему;
- тяжелую атмосферу на всю страницу;
- ощущение, что сайт больше про стиль, чем про понятное решение.

## Следующий шаг

Переделывать фактическую страницу `/reconstruction` под C2 + C3:

```text
живые реальные фото + светлая материальная основа + тонкие линии + блоки наблюдений + одна темная секция для главного вопроса + один понятный CTA.
```
