```text

```

```text

```

## 4. Условия первого осмотра

Сначала клиент присылает:

```text
фото, местоположение, короткое описание задачи
```

После этого:

```text
смотрим материалы, задаем вопросы, решаем нужен ли разговор или осмотр
```

Выезд:

```text
условия не решены
```

Нужно решить:

```text
выезд платный или бесплатный;
что с дальними регионами;
кто оплачивает дорогу;
есть ли минимальный размер задачи для выезда;
можно ли делать осмотр до покупки дома.
```

## 7. Фото мастера в работе

Есть ли фото:

```text

```

Какой кадр нужен:

```text
мастер на объекте, руки, дерево, инструмент, процесс, без постановочного корпоративного портрета
```

## 8. Заявки

Текущий режим:

```text

```

План:

```text
подключить Telegram-бота
```

Нужно решить:

```text
какие поля бот должен получать;
куда складывать фото;
кто получает уведомление;
нужен ли email-дубль.
```
