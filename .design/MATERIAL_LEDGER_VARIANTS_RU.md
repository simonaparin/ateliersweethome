# Material Ledger Variants

Дата: 2026-07-25

## Цель

Показать варианты внутри выбранного направления C / Material Ledger.

Это не возврат к A/B/C. База уже выбрана:

```text
Material Ledger
```

Теперь выбираем, как именно его делать.

## Preview

```text
MATERIAL_LEDGER_VARIANTS_PREVIEW.html
```

## Variant C1: Ledger Classic

Смысл:

```text
самый ясный, самый SEO-дружелюбный, похож на аккуратную ведомость осмотра
```

Плюсы:

- понятно;
- легко масштабировать на крыши и кухни;
- хорошо держит блоки "что смотрим";
- не требует большого портфолио.

Риск:

```text
может быть слишком сухим, если не добавить хорошие фото и живые подписи
```

## Variant C2: Photo Ledger

Смысл:

```text
фото первичны, структура остается, но страница ощущается живее
```

Плюсы:

- лучше показывает реальные материалы;
- меньше ощущения документа;
- подходит для реконструкции и летних кухонь;
- легче продавать вкус и ремесло.

Риск:

```text
если фото слабые, вариант теряет силу
```

## Variant C3: Dark Insert Ledger

Смысл:

```text
Material Ledger с темными акцентными вставками из B
```

Плюсы:

- сохраняет выбранную структуру C;
- добавляет силу и мастерскую атмосферу B;
- хорошо подходит для крыши, конструкций, деталей;
- не делает весь сайт темным.

Риск:

```text
если темных зон будет много, снова вернемся к B
```

## Моя рекомендация

Решение принято:

```text
C2: Photo Ledger
```

И добавить одну темную секцию из C3 ниже первого экрана.

Почему:

- фотографии у нас реальные, их нужно делать главным материалом;
- структура C сохраняется;
- страница не становится сухой таблицей;
- темный акцент из B остается, но не рулит всей системой.

## Статус

Это направление принято пользователем.

Дальше фактическая страница `/reconstruction` переделывается по формуле:

```text
C2 база + одна темная секция C3
```
