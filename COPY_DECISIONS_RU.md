# Copy Decisions

## Базовая фраза

Использовать как основную смысловую формулу страницы реконструкции:

> Старый дом может стать тёплым, светлым и удобным, сохранив свой характер.

Не заменять эту фразу на "креативные" варианты, которые не объясняют предложение.

Причина:

```text
эта формулировка непонятная и не объясняет предложение;
пользователь явно выбрал фразу про теплый, светлый, удобный дом с сохранением характера.
```

## Где фраза уже стоит

```

seo.ogDescription
hero.mainPhrase
```
