# Контентная архитектура Atelier Sweet Home

Цель: каждая страница должна быть самостоятельной посадочной из Google, а не разделом общего сайта "мы делаем всё".

На старте рабочая страница только одна:

- `/reconstruction` — реконструкция старых домов.

Будущие страницы:

- `/roof` — крыши старых частных домов.
- `/summer-kitchen` — летние кухни, навесы, микроцемент, уличная рабочая зона.

Главную страницу пока не делаем.

## Общая логика

Каждая страница отвечает на один главный вопрос человека:

| URL | Человек ищет | Что страница должна доказать |
| --- | --- | --- |
| `/reconstruction` | старый дом можно привести к жизни или нет | мы умеем смотреть старый дом целиком и отделять "сохранить" от "усилить" и "заменить" |
| `/roof` | крыша течет, старая, слабая, нужна замена или переделка | мы понимаем крышу как конструкцию, а не только как покрытие |
| `/summer-kitchen` | нужна красивая летняя кухня, навес, микроцемент, рабочая зона | мы можем сделать современную вещь руками и довести до аккуратного результата |

Внизу каждой страницы можно показать другие направления, но коротко:

- на реконструкции: "если вопрос начинается с крыши или летней кухни, это можно вынести отдельным этапом";
- на крыше: "если крыша часть общей реконструкции дома, можно смотреть дом шире";
- на кухне: "если участок и старый дом требуют большего плана, можно обсудить реконструкцию".

## `/reconstruction`

### Позиция

Старый дом может стать теплым, светлым и удобным, сохранив свой характер.

Это не музейная реставрация и не снос ради новой коробки. Сначала смотрим дом, потом решаем, что сохранить, что усилить, а что заменить.

### Главный CTA

Прислать фотографии дома.

## Где нужен API

API нужен не сейчас, а перед финальной SEO-картой и рекламой.

Без API можно:

- собрать структуру страниц;
- написать честные тексты;
- разложить фото;
- сделать техническое SEO;
- подготовить черновые кластеры запросов.

С API нужно будет:

- проверить частотность;
- найти похожие запросы;
- понять конкуренцию;
- выбрать основные заголовки;
- решить, какие страницы делать первыми;
- собрать объявления Google Ads.

Подходящие инструменты:

- Semrush — быстро смотреть ключи, конкурентов и сложность;
- DataForSEO — дешевле и гибче для SERP/keyword API;
- SerpApi — смотреть реальную выдачу Google по запросам и регионам.

## Что не делать

- не создавать отдельные страницы по районам без реального содержания;
- не повторять один и тот же текст на разных страницах;
- не писать "фиксированная цена за квадрат";
- не обещать сроки, гарантии и точную стоимость без осмотра;
- не делать страницу бань главным направлением до появления материала;
- не переводить грузинский текст в публикацию без проверки носителем.
